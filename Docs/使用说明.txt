QJAR 工具 1.0.0
==============

免安装单文件：解压后双击 QJAR工具.exe 即可运行。
QJAR工具.exe 必须与 QJCore.dll 放在同一目录。


一、注册一台设备
----------------
1. 控制器默认地址为 192.168.2.100:7625，显示在左侧，平时是只读的灰色底。
   要改地址点“修改”，四段 IP 与端口才可编辑：每段最多三位，输满自动前进，点号和小数点键切换下一段，可粘贴完整 IP。
   改完点“保存”（或按 Enter）生效并记住，下次启动自动载入；点“取消”（或按 Esc）放弃本次修改。
   保存前会检查每段 0-255、端口 1-65535。
2. 点“查询状态”读取设备序列号与授权状态。
3. 首次使用时以普通用户身份运行，要注册设备请在左侧点“管理员登录”并输入密码。
   登录状态会被记住：关闭程序再打开仍然是管理员，直到点“退出管理”才切回普通用户。
   设备未授权时点“注册设备”。注册写入完成后，程序会再次查询授权状态确认是否生效，
   然后通过 SSH 连接 192.168.1.200 发送示教器重启命令。
4. 点“重启示教器”可单独重启动一次示教器（同样需要管理员登录）。
5. 操作过程中可以点“取消”停止本地等待；已经发出的注册请求无法撤回，请再用“查询状态”确认结果。


二、命令调试
------------
1. 点左侧“命令调试”标签切页。发送命令需要先做管理员登录，普通用户只能查看。
2. 输入命令，例如 getlic；有独立数据时填写“数据”。
3. 编码默认 UTF-8，点“编码：UTF-8”切换到 GBK；超时默认 5000 ms，可改 1-600000。
4. 点“发送命令”发出报文，“收发记录”显示请求和回包；点“清空”清除当前记录。


三、界面说明
------------
- 状态区显示当前设备状态：等待查询 / 正在连接控制器 / 已授权 / 注册结果待确认 / 操作失败。
- 进度条显示本次操作的进度，下方左侧是状态说明、右侧是百分比。
- 提示条说明当前需要注意的事项，例如“注册请求已发出，结果未确认；请用‘查询状态’复查”。
- 注册页和命令调试页各有一份日志，可以“清空”，或点“导出日志”手动保存。
- 界面不显示、不保存完整注册码。


四、文件位置
------------
- 连接设置：%LOCALAPPDATA%\QJAR\settings.ini
- 导出的日志：保存到“导出日志”对话框中选择的位置。


五、系统要求
------------
- Windows 10 1809（64 位）及以上，支持高 DPI 显示器。
- 自动重启使用 Windows OpenSSH 客户端（系统可选功能），示教器需开放 SSH 22 端口并允许 root 空密码登录。
  首次连接记录 SSH 主机密钥；密钥变化会停止重启并在日志中报错。
  “重启命令已发送”表示示教器已接受命令，不表示开机完成；SSH 失败不会改变控制器已激活的结果。
