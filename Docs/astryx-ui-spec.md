# QJAR 工具 UI 规格（源：Astryx 设计系统）

取值全部来自 `@astryxdesign/cli` 0.7.16 的 token 文档（`astryx docs tokens-*`，原始导出见 `astryx-tokens-raw.txt`）。
本工具是 Windows 原生自绘界面，只取**浅色主题**；单位是 96 DPI 下的 px，运行时按 DPI 缩放。

## 2. 字号与字重

| 用途 | 字号 | 字重 | 行高 | token |
| --- | --- | --- | --- | --- |
| 页面标题 | 20 | 600 | 1.4 | heading-2 |
| 卡片标题 | 17 | 600 | 1.41 | heading-3 |
| 正文 / 字段值 | 14 | 500 | 1.45 | font-size-base |
| 字段名 / 辅助文字 | 12 | 400 | 1.4 | font-size-sm |
| 日志 / 命令输出 | 12 | 400 | 1.5 | font-size-code |
| 天数等强调数字 | 20 | 600 | 1.33 | heading-2 |

字体：页面标题 `QJAR 工具` 使用内嵌的**源流明体**（`Assets/QJToolDisplay.otf`，OFL 许可随源码保留）；正文、字段名、按钮、日志使用 `PingFang SC`（本机已装）→ 后备 `Microsoft YaHei UI`；等宽 `Consolas` → `"SF Mono", Monaco`。所有文字高度按 `Theme.Line(font)`（= 字体行高 + 2px）取值，避免中文被裁。

## 6. 边框、阴影、焦点

- 描边：`1px rgba(5,54,89,0.1)`
- 卡片阴影（low）：`0 1 1 rgba(0,0,0,0.10), 0 2 8 rgba(0,0,0,0.10)`
- 弹窗阴影（high）：`0 2 2 rgba(0,0,0,0.10), 0 8 24 rgba(0,0,0,0.30)`
- 焦点环：`2px` 实线 `#0064E0`，外偏 `3px`（键盘焦点才画，鼠标点击不画）
- 输入无效：`inset 0 0 0 2px rgba(227,25,59,0.3)`

## 7. 动效

- 悬停 / 按下 / 状态切换：`175ms`，`cubic-bezier(0.24, 1, 0.4, 1)`
- 页面切换、日志新行进入：`410ms`，同上曲线；退出用 `cubic-bezier(0.3, 0, 0.6, 0.6)`
- 系统开启“减少动态效果”时，以上全部降为瞬时（0 ms）。

| NavList（SegmentedTabs 竖排） | 侧栏顶部“注册 / 命令调试” | 每行高 36、占满侧栏宽度，白底 + 1px 描边 + 圆角 8，左侧 16px 线性图标；选中 = `accent-muted` 底 + `accent` 描边 + 蓝色加粗文字；悬停 = `overlay-hover` 底；上下方向键可切换 |

| Banner | “注册结果待确认” / 错误 | 12px 文字，muted 底色，圆角 12，内边距 12×8 |
| Dialog | 管理员登录 | 白卡圆角 12 + high 阴影，遮罩 `#01122866` |
| Tooltip | 字段说明（原需求已要求去掉小字提示，仅保留必要错误） | 14px 正文色，深底反白 |

## 9. 布局

```
┌──────────────┬────────────────────────────────────────────┐
│ 注册          │ ← 侧栏竖排导航，切换页面                     │
│ 命令调试      │ ┌ 状态卡 ────────────────────────────────┐ │
│               │ │ 设备状态 · 序列号 · 剩余天数             │ │
│ 控制器地址     │ └───────────────────────────────────────┘ │
│ IP + 端口      │ ┌ 操作卡 ────────────────────────────────┐ │
│               │ │ 主操作 / 次要操作 · 进度条 · 状态文案     │ │
│               │ └───────────────────────────────────────┘ │
│ 管理员登录     │ ┌ 日志卡 ────────────────────────────────┐ │
│               │ │ 等宽日志（可选中、可滚动）                │ │
└──────────────┴────────────────────────────────────────────┘
```

- 窗口 1024×640，最小 880×560。
- 侧栏固定 288px，工作区自适应；卡片之间 16px，卡片内边距 20px；工作区顶部留 36px 标签条。
- 一屏一任务：注册页只有“查询状态 / 注册设备 / 取消”，命令页只有“发送命令 / 清空 / 重启示教器”。

## 10. 状态语义

| 设备状态 | 颜色 | 文案 |
| --- | --- | --- |
| 未查询 | `text-secondary` | 等待查询 |
| 正在连接 / 查询中 | `accent` | 正在连接控制器 |
| 已授权 | `success` | 已授权 · 剩余 N 天 |
| 待确认 | `warning` | 注册结果待确认 |
| 失败 | `error` | 具体错误原因 |

颜色不单独承载信息：每种状态同时有文案，徽标另有圆点形状区分。
## 11. 实测与实现说明

| 项 | 结果 |
| --- | --- |
| 发布体积 | QJAR工具.exe 105,984 B + QJCore.dll 150,528 B = 256,512 B（目标 ≤ 2,000,000 B） |
| 冷启动 | 约 2.5 s（首次运行含杀毒扫描） |
| 热启动 | 1.40–1.59 s（同一台机器，旧命令工具为 2.5–3.0 s） |
| 空闲私有工作集 | 33.7 MB（原目标 30 MB，已同意放宽到 60 MB） |
| 高 DPI | 通过 QJAR.exe.config + 清单启用 PerMonitorV2；本机 100% DPI 实测，125%/150% 未实测 |

实现时对规格的偏离，均为桌面 Win32 限制或刻意简化：

1. **焦点环内嵌**：Win32 子控件不能绘制到自身边界之外，规范里的「2px accent、外偏 3px」改为控件内侧 2px 描边，视觉强度一致。
2. **卡片用 1px 描边、不用阴影**：shadow-low 在自绘 GDI 里代价高且发灰；阴影只保留给需要浮起的面板（本版没有浮层，登录改为侧栏内联）。
3. **地址默认只读**：字段平时是浅灰底、只读，点「修改」才变成可编辑，出现「保存 / 取消」（Enter 保存、Esc 取消），保存后回到只读并写入 `%LOCALAPPDATA%\QJAR\settings.ini`。避免现场误触改掉地址。
4. **空态提示**：RichTextBox 与 TextBox 是子窗口，会盖住父控件的绘制，提示文字改为画在子窗口内部。
5. **动效**：只在按钮悬停/按下与进度条数值变化上做 175 ms / 410 ms 缓动；系统开启「减少动态效果」时全部瞬时完成。
6. **页面切换是侧栏里的竖排导航**：最初做成侧栏纯文字列表，看起来像标题、看不出能点；改成有底色的整行条目（选中 `accent-muted`、悬停 `overlay-pressed`），既有明确的可点感，也符合竖排的侧栏布局。
7. **标题字体**：页面标题用内嵌的源流明体（`QJToolDisplay.otf`），通过 `PrivateFontCollection.AddMemoryFont` 加载——`AddFontMemResourceEx` 注册的字体 GDI+ 经常解析不到。
